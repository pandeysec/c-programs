# Student Grade System in C

This is a simple C programming project that takes marks of 5 subjects from the user and performs different calculations.

## Features
- Takes input of 5 subject marks
- Calculates total marks
- Calculates percentage
- Finds maximum marks
- Finds minimum marks
- Displays grade using if-else conditions

## Concepts Used
- Arrays
- Loops
- If-Else Ladder
- Conditional Statements
- Basic Calculations
- scanf() and printf()

## Grading System

| Percentage | Grade |
|------------|-------|
| 90 and above | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 40 - 59 | D |
| Below 40 | Fail |
